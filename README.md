# Ayu Fidyaningrum — Motion Portfolio

A responsive, editorial-style personal portfolio built with React, Vite and GSAP.

## Run locally

1. Install Node.js (18+ recommended).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. Run `npm run build` to create the production build in `dist/`.

## First customisations

- Replace the placeholder email `hello@ayufidyaningrum.com` with your preferred professional email.
- Add your real LinkedIn and Upwork URLs in `src/main.jsx`.
- Replace the three sample project cards with verified projects, images, deliverables and measurable outcomes.
- Confirm experience dates and wording before publishing.
- Add a custom domain and deploy the `dist/` folder to Vercel, Netlify or another static hosting provider.

## Motion

GSAP intro timeline, ScrollTrigger reveals, rotating hero orbit and scroll-linked marquee are implemented in `src/main.jsx`. The layout includes a reduced-motion CSS fallback.

## Notes

Project descriptions and contact details are editable placeholders. Do not publish unverified client claims or confidential work.
